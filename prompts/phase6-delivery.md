# Phase 6 — Delivery

Three artifacts: two `.docx` per batch (the main document and the PROMPTS document) and one upload sheet for the round.

## The two `.docx` per batch

One pair per batch (angle x level, B1 to B15), **not per image**, because the copy is the same across the three variations. Both live **in the batch folder, next to the 3 images**:

```
AA BRAND-SKU T101-TF-B1/AA BRAND-SKU T101-TF-B1.docx             <- main document
AA BRAND-SKU T101-TF-B1/AA BRAND-SKU T101-TF-B1 - PROMPTS.docx   <- the prompts of the 3 images
AA BRAND-SKU T101-TF-B1/AA BRAND-SKU T101-TF-B1-V1.png           <- and -V2.png, -V3.png
```

`TF` = top of funnel, `FF` = bottom of funnel. Separators are always hyphens, never dots. The source `.md` files stay in `drafts/`, references in `support/`.

### Formatting (house document standard)

Arial 12pt, 1.5 line spacing, black, margins 3-3-2-2 cm. Every field has its **label in ALL CAPS and bold** and its content **on the line below**. Generated by the script, not by hand:

```bash
python "$HOME/.claude/skills/longform-builder/scripts/build_batch_docx.py" \
    --draft drafts/B1.md --funnel TF      # writes to AA BRAND-SKU T101-TF-B1/
python "$HOME/.claude/skills/longform-builder/scripts/build_batch_docx.py" \
    --folder drafts/ --funnel TF          # all of them, B1 to B15
```

Use `--author` for a second execution of the same matrix by another writer. The script warns when the frontmatter has no `profile` or `angle_summary`, or when the draft's CTA does not match the funnel stage.

### The main document

In this order:

1. **Document name** (centered)
2. **ANGLE** — `Angle N - Name`, and on the line below the one-sentence summary (frontmatter `angle_summary`)
3. **AWARENESS LEVEL** — the label (`Problem aware`, `Solution aware`, `Hidden cause`), and on the line below a one-sentence summary (the level's default line, or frontmatter `level_summary`)
4. **PROFILE** — the Meta page that runs the batch (frontmatter `profile`, see `knowledge/publishing-profiles.md`)
5. **HEADLINE** — link headline
6. **DESCRIPTION** — link description
7. **CTA** — set by the funnel stage, not by the draft: TF = Learn more, FF = Shop now
8. **COPY** — the primary text, paragraph by paragraph

The "first three lines" block is not in any document: it duplicated the opening of the copy and could be pasted twice into Meta. The see-more cut is checked in the draft and at the gate.

### The PROMPTS document

`{standard name} - PROMPTS.docx`, in the same folder. Centered title, then for each image: `V1 - {image filename}.png` in bold, the variation label, and the **full prompt**, read from `image-brief.md`. If an image is regenerated, rebuild the document so the prompt still matches the image.

It replaces the former pair of "copy-only docx + `infos/... INFOS.docx`". When migrating an older round, move the old documents to `support/old-docx/` and delete nothing.

## The upload sheet

`upload.csv`, one row per ad (45 in a 5 x 3 x 3 round), in the format the media buyer uploads:

| Column | Content |
|---|---|
| `campaign` | name of the test campaign (default `T101 Long Form TF`) |
| `ad_set` | one per batch (the ad set is what receives the $100): `T101-TF-B1` |
| `profile` | the Meta page that runs the batch |
| `ad` | `AA BRAND-SKU T101-TF-B1-V1` |
| `image` | filename: `AA BRAND-SKU T101-TF-B1-V1.png` |
| `primary_text` | the long-form copy |
| `headline` | link headline |
| `description` | link description |
| `cta` | button, by funnel stage: Learn more (TF) or Shop now (FF) |
| `destination` | destination URL |
| `angle` / `angle_num` / `level` / `variation` / `cluster` | the dimensions, for the later read. `level` carries the label, `Problem aware (A)`, read from the draft frontmatter; `cluster` is the variation label from `image-brief.md` |

Rows come out in numeric batch order (B1, B2, ... B10, not B1, B10, B2).

The dimension columns exist so `creative-intel` can read the round without rebuilding the classification. **That is what closes the loop**: the round is born already classified, and the funnel stage in the name lets tracking cross performance by stage.

```bash
python "$HOME/.claude/skills/longform-builder/scripts/build_batch_docx.py" \
    --sheet --test T101 --product BRAND-SKU --funnel TF --destination "https://..." --out upload.csv
```

## Final logging

1. Update `tracking/batches.json`: everything to `delivered`
2. Update `progress.md`
3. **Add every angle and hook to the product's `kill-list.md`**, with the matching file, so the next round does not repeat it
4. Log one line in the product's `progress.md` pointing at the test folder

## What to tell the user at closing

Two things, always:

- **The reading floor.** No conclusions before $850.85 per cell or 10 conversions. A cell crosses that floor in a few days; before it does, any read is noise.
- **Do not promote on CTR.** On this account, hook rate is not monotonic. High CTR on the image is not a winner signal. The signal is sales.
